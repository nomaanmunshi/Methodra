# Changelog

## 1.0.0-demo

- Native Android Compose application with original stone onboarding.
- Deterministic Method Engine and ten-method catalog.
- Four book-inspired protocol collections with conservative evidence labels.
- One active protocol, setup questions, difficult-day version, daily check-in and recovery reason.
- Focus sessions, selected-app rules, local usage budgets, recurring focus schedules, emergency exit and optional AccessibilityService protection.
- Personal Lab with one primary metric, daily adherence and conservative review language.
- Local JSON export and deletion.
- Java 21 Spring Boot backend with method catalog, matching API, authentication and optimistic sync document endpoint.
- PostgreSQL/Flyway/Testcontainers configuration and GitHub CI/release workflows.
