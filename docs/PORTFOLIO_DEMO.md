# Two-minute portfolio demo path

1. **Opening (0:00–0:15)** — show the original stone and skip/reduced-motion path. Explain that the metaphor is vague intention becoming a concrete method, not a “broken user”.
2. **Method Engine (0:15–0:45)** — choose Study, a concrete outcome, delayed start and screen distraction. Show the top three deterministic matches and their visible reasons.
3. **Protocol setup (0:45–1:05)** — choose If–Then Start Protocol and answer its two setup questions. Show those answers on Today beside the difficult-day version.
4. **Focus (1:05–1:30)** — show selected distracting apps, a 35-minute block, usage permission disclosure and a recurring schedule. Be explicit that AccessibilityService blocking is optional and bypassable.
5. **Evidence (1:30–1:45)** — open Methods, show evidence level, limitation and source link; then show one Level C book-inspired collection.
6. **Lab (1:45–2:00)** — create/log a 14-day trial and point out the wording: association during the trial, not causal proof.

End on the architecture diagram/readme: local-first Android client, deterministic engine, Java 21 Spring Boot modular monolith, PostgreSQL/Flyway and CI.
